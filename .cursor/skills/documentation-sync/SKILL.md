# Documentation sync

1. Inspect actual code changes.
2. Update `docs/architecture/` and `docs/guides/` as needed.
3. Add or amend ADRs for significant decisions.
4. Verify commands in `README.md` and `docs/DEVELOPMENT.md`.
5. Remove stale claims.
6. Never mark incomplete roadmap work as completed.
